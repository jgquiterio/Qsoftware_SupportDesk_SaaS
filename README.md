# SupportDesk SaaS

**Multi-Tenant Customer Support Management Platform**

SupportDesk SaaS is a customer support management platform designed to help businesses organize customer service operations, manage support tickets, and monitor team performance.

## Features

- User authentication and authorization
- Multi-tenant architecture
- Company management
- User and role management
- Support ticket management
- Ticket assignment
- Priority and status tracking
- Ticket activity history
- Administrative dashboard
- Basic reports

## Technology Stack

| Technology | Purpose |
|---|---|
| Laravel | Backend |
| Vue.js | Frontend |
| MySQL | Database |
| Bootstrap / AdminLTE | User Interface |
| Docker | Development Environment |

## Multi-Tenant Architecture

The application is designed to support multiple companies within a single platform.

Each company has its own users and support tickets, with data isolation to prevent unauthorized cross-company access.

## Ticket Management

Tickets support the following statuses:

- Open
- In Progress
- Pending
- Closed

Priority levels:

- Low
- Medium
- High
- Urgent
